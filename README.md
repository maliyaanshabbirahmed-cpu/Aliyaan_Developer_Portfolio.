A personal developer portfolio built with Python and Streamlit.

## Included sections
- Personal introduction and profile photograph
- About section
- Three project cards with live application links
- Technical skills grouped by subject
- Education and career direction

## Run locally

1. Install Python 3.10 or newer.
2. Extract this ZIP.
3. Open a terminal in the extracted project folder.
4. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

5. Start the app:

   ```bash
   streamlit run app.py
   ```

## Deploy to Streamlit Community Cloud

1. Create a new GitHub repository and upload the extracted project files.
2. Open https://share.streamlit.io/ and sign in.
3. Choose **Create app** and select your repository.
4. Set the main file path to `app.py`.
5. Deploy.

The repository must contain `app.py`, `requirements.txt`, and the `assets/` folder.
